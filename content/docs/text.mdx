Standard Markdown and GitHub-flavored Markdown (GFM) work in every docs page.

## Headings

Heading levels structure the page and feed the right-rail "On this page"
navigation. Prefer starting body content at `##` — the page title already comes
from frontmatter.

```markdown
## Section

### Subsection
```

## Emphasis

```markdown
**bold**, _italic_, and ~~strikethrough~~
```

**bold**, _italic_, and ~~strikethrough~~

## Links

```markdown
[Configuration](/docs/configuration)
```

[Configuration](/docs/configuration)

External links open in a new tab when written as normal Markdown URLs.

## Blockquotes

```markdown
> Useful for short pull-quotes or callouts you do not want as a component.
```

> Useful for short pull-quotes or callouts you do not want as a component.

For colored callouts with icons, prefer
[Callout](/docs/components/callout) components instead.

## Tables

GFM tables are supported:

```markdown
| Name | Type   |
| ---- | ------ |
| id   | string |
| age  | number |
```

| Name | Type   |
| ---- | ------ |
| id   | string |
| age  | number |

## Horizontal rules

```markdown
---
```

Three or more hyphens on their own line render a rule. Avoid putting them at
the very top of the file — that is frontmatter territory.
