Shiso turns a folder of Markdown and MDX files into a fast, fully static
documentation site. Everything about the site — navigation, branding, SEO,
redirects — lives in one `docs.json` file, so the whole site can be configured
in one place.

## How it works

- Write pages as `.mdx` (or `.md`) files under `content/docs`
- Describe your site once in `docs.json`
- Build to plain HTML with `pnpm build` — every page is prerendered, then
  hydrated into a client-side app for instant navigation

## What you get

- **Validated configuration**: supported `docs.json` keys are strictly
  validated, with clear errors for malformed or unknown options
- **Site chrome**: navbar links and buttons, footer socials and link columns,
  and a dismissible announcement banner
- **Theming**: light/dark modes, accent colors, custom fonts, and backgrounds
- **SEO built in**: canonical URLs, Open Graph tags, structured data,
  `sitemap.xml`, redirects, and last-modified timestamps from git history
- **Docs components**: callouts, tabs, steps, cards, code groups, and more,
  available in every page without imports

## Project structure

A typical Shiso project looks like this:

```text
my-docs/
├── content/
│   ├── docs/            # Documentation pages (.md and .mdx)
│   │   ├── index.mdx    # First page of the docs
│   │   └── ...
│   └── pages/           # Standalone pages, such as a landing page
├── public/              # Static assets served as-is (logo, favicon, images)
│   └── logo.svg
├── docs.json            # Site configuration: navigation, branding, SEO
├── shiso.config.ts      # Project settings: site URL, content directory
├── styles.css           # Optional CSS overrides for the site
├── index.html           # HTML shell used by the build
├── entry-client.tsx     # Client entry point that mounts the app
└── package.json
```

The two files you edit most are `docs.json`, which describes the site and its
navigation, and the files under `content/docs`, which hold the pages
themselves. Everything else is wiring that rarely changes after setup.
