After you complete this guide, you will have Shiso running locally with your
own pages in the sidebar.

## Before you begin

Shiso is a docs-as-code site: every page is a Markdown or MDX file under
`content/docs`, and the whole site is configured in a single `docs.json`.

You need:

- [Node.js](https://nodejs.org/) 20+
- [pnpm](https://pnpm.io/) (npm or yarn also work)

## Set up the project

<Steps>
  <Step title="Clone or open the repository">
    ```bash
    git clone https://github.com/umami-software/shiso.git
    cd shiso
    ```

    Or open your existing fork if you already have one.
  </Step>

  <Step title="Install dependencies">
    <CodeGroup>
      ```bash pnpm
      pnpm install
      ```

      ```bash npm
      npm install
      ```
    </CodeGroup>
  </Step>

  <Step title="Start the dev server">
    ```bash
    pnpm dev
    ```

    Open [http://localhost:8001/docs](http://localhost:8001/docs). You should
    see this documentation site with the sidebar from `docs.json`.
  </Step>
</Steps>

## Make your first change

<Steps>
  <Step title="Edit a page">
    Open `content/docs/index.mdx` and update the description in the frontmatter:

    ```mdx
    ---
    title: "Introduction"
    description: "Your custom description here"
    ---
    ```
  </Step>

  <Step title="Add a page to navigation">
    Create `content/docs/hello.mdx`:

    ```mdx
    ---
    title: Hello
    description: My first custom page.
    ---

    Hello from Shiso.
    ```

    Then list it under Getting started in `docs.json`:

    ```json
    {
      "group": "Getting started",
      "pages": ["index", "quickstart", "hello"]
    }
    ```

    Refresh the browser — **Hello** appears in the sidebar.
  </Step>

  <Step title="Rename the site">
    Set your product name in `docs.json`:

    ```json
    {
      "name": "My Docs",
      "description": "Documentation for my product."
    }
    ```

    The header and browser tab update immediately in dev.
  </Step>
</Steps>

## Build for production

```bash
pnpm build
```

The build validates `docs.json`, prerenders every page to static HTML in
`dist/client`, and writes `sitemap.xml` when `$shiso.siteUrl` is set. Preview
the output with:

```bash
pnpm preview
```

Deploy `dist/client` to any static host — see
[Deployment](/docs/guides/deployment).
