title: Param Field
description: Document request parameters with location and type badges.
---

Use `ParamField` for query, path, header, or body parameters, and `Param` for
inline parameter names.

## Props

### `ParamField`

- `name?: string`
- `query?: string` / `path?: string` / `header?: string` / `body?: string`
- `type?: string`
- `required?: boolean`
- `children?: ReactNode`

### `Param`

- `children?: ReactNode`

## Basic usage

```tsx
<ParamField name="limit" query="limit" type="number" required>
  Maximum number of records to return.
</ParamField>
```

<ParamField name="limit" query="limit" type="number" required>
  Maximum number of records to return.
</ParamField>

## Location variants

```tsx
<ParamField path="userId" type="string" required>
  User id in the URL path.
</ParamField>

<ParamField header="Authorization" type="string" required>
  Bearer token.
</ParamField>
```

## Inline parameter names

```tsx
Set <Param>limit</Param> and <Param>offset</Param> together for pagination.
```

Set <Param>limit</Param> and <Param>offset</Param> together for pagination.

## Behavior notes

- the location badge is inferred from `query`, `path`, `header`, or `body`
- if several location props are set, precedence is
  `query` → `path` → `header` → `body`
- the display label is `name`, or the first location prop value when `name` is
  omitted
