title: Frame

---

Use `Frame` to visually contain media or custom content with an optional
caption.

## Basic usage

<Frame caption="Docs layout preview">
  ![Sample](/images/sample.jpg)
</Frame>

```mdx
<Frame caption="Docs layout preview">
  ![Sample](/images/sample.jpg)
</Frame>
```
