---
title: Frame
description: Styled borders, hints, and captions for screenshots or other media.
---

Use `Frame` to visually contain media or custom content with optional hints and
captions.

## Basic usage

<Frame caption="Docs layout preview">
  <img src="/images/sample.jpg" alt="Sample" />
</Frame>

```tsx
<Frame caption="Docs layout preview">
  <img src="/images/sample.jpg" alt="Sample" />
</Frame>
```

## Markdown captions

Caption strings support Markdown links, bold, italic, and inline code.

<Frame caption="**Sample:** Learn more in the [images guide](/docs/images).">
  <img src="/images/sample.jpg" alt="Sample" />
</Frame>

```tsx
<Frame caption="**Sample:** Learn more in the [images guide](/docs/images).">
  <img src="/images/sample.jpg" alt="Sample" />
</Frame>
```

## Hints

Use `hint` to display text before the frame. You can combine it with a caption.

<Frame hint="Use a high-resolution source image." caption="Docs layout preview">
  <img src="/images/sample.jpg" alt="Sample" />
</Frame>

```tsx
<Frame hint="Use a high-resolution source image." caption="Docs layout preview">
  <img src="/images/sample.jpg" alt="Sample" />
</Frame>
```

## Autoplay videos

Videos with `autoPlay` automatically receive `playsInline`, `loop`, and `muted`
attributes. Videos without `autoPlay` are left unchanged.

```tsx
<Frame caption="Product demo">
  <video autoPlay src="/videos/product-demo.mp4" />
</Frame>
```

## Properties

<PropertiesTable>
<ResponseField name="caption" type="ReactNode">
  Optional centered caption below the framed content. String values support inline Markdown.
</ResponseField>

<ResponseField name="hint" type="ReactNode">
  Optional text displayed before the frame. String values support inline Markdown.
</ResponseField>

<ResponseField name="children" type="ReactNode">
  Media or other content to frame.
</ResponseField>
</PropertiesTable>
