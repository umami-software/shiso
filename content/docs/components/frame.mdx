---
title: Frame
description: Border and caption for screenshots or other media.
---

Use `Frame` to visually contain media or custom content with an optional
caption.

## Props

- `caption?: ReactNode`
- `children?: ReactNode`

## Basic usage

```mdx
<Frame caption="Docs layout preview">
  ![Sample](/images/sample.jpg)
</Frame>
```

<Frame caption="Docs layout preview">
  ![Sample](/images/sample.jpg)
</Frame>

## With code or other children

```tsx
<Frame caption="Environment variables in `.env`">
  <code>VITE_API_URL=https://api.example.com</code>
</Frame>
```
