Use `Steps` and `Step` for ordered how-tos.

## Props

### `Steps`

- `children?: ReactNode` — one or more `Step` children

### `Step`

- `title?: ReactNode` — falls back to `Step 1`, `Step 2`, …
- `children?: ReactNode`

## Basic usage

```tsx
<Steps>
  <Step title="Install dependencies">Run your package manager install command.</Step>
  <Step title="Configure docs">Set navigation in `docs.json`.</Step>
  <Step title="Start the app">Run the local development server.</Step>
</Steps>
```

## Behavior notes

- step numbers are assigned automatically in document order
- empty groups render nothing
