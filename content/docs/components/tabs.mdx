Use `Tabs` and `Tab` when readers should choose among alternatives in the same
space — languages, platforms, or product modes. For tabbed **code** only,
prefer [Code Group](/docs/components/code-group).

## Basic usage

<Tabs>
  <Tab title="JavaScript">
    Install with npm.
  </Tab>
  <Tab title="Python">
    Install with pip.
  </Tab>
</Tabs>

```tsx
<Tabs>
  <Tab title="JavaScript">
    Install with npm.
  </Tab>
  <Tab title="Python">
    Install with pip.
  </Tab>
</Tabs>
```

## Persist selection with `group`

Tabs that share a `group` id restore the last selected tab from
`localStorage` under `shiso-tabs:<group>`.

```tsx
<Tabs group="language">
  <Tab title="Node">Node instructions…</Tab>
  <Tab title="Go">Go instructions…</Tab>
</Tabs>
```

A single `Tab` child renders as plain content with no tab chrome.

## Properties

### Tabs

<ResponseField name="group" type="string">
  Shared id for persisting the selected tab across tab sets.
</ResponseField>

<ResponseField name="children" type="ReactNode">
  One or more `Tab` children.
</ResponseField>

### Tab

<ResponseField name="title" type="ReactNode">
  Tab label. Falls back to `Tab 1`, `Tab 2`, and so on.
</ResponseField>

<ResponseField name="children" type="ReactNode">
  Panel content.
</ResponseField>
