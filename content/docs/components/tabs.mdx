title: Tabs

Use `Tabs` and `Tab` when readers should choose among alternatives in the same
space — languages, platforms, or product modes.

## Props

### `Tabs`

- `group?: string` — share selection across tab sets via `localStorage`
- `children?: ReactNode` — one or more `Tab` children

### `Tab`

- `title?: ReactNode` — tab label (falls back to `Tab 1`, `Tab 2`, …)
- `children?: ReactNode`

## Basic usage

```tsx
<Tabs>
  <Tab title="JavaScript">
    Install with npm.
  </Tab>
  <Tab title="Python">
    Install with pip.
  </Tab>
</Tabs>
```

<Tabs>

    Install with npm.
  </Tab>

  </Tab>

## Persist selection with `group`

Tabs that share a `group` id restore the last selected tab from
`localStorage` under `shiso-tabs:<group>`.

```tsx
<Tabs group="language">
  <Tab title="Node">Node instructions…</Tab>
  <Tab title="Go">Go instructions…</Tab>
</Tabs>
```

## Behavior notes

- a single `Tab` child renders as plain content with no tab chrome
- for tabbed **code** only, prefer [Code Group](/docs/components/code-group)
