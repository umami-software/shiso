---
title: Code Group
description: Tabbed code snippets for package managers, languages, and variants.
---

Use `CodeGroup` to show multiple related fenced blocks behind tabs.

## Props

- `children?: ReactNode` — fenced code blocks (or other tabbable content)

Each child can set a label with:

- a second token after the language fence (`` ```bash pnpm ``)
- or a `title` prop when the child is an element

If no label is found, Shiso infers one from the language class and suffixes
duplicates (`bash`, `bash 2`, …).

## Basic usage

````mdx
<CodeGroup>
  ```bash npm
  npm install
  ```

  ```bash pnpm
  pnpm install
  ```
</CodeGroup>
````

<CodeGroup>

## Behavior notes

- one child renders as plain content with no tab chrome
- for non-code alternate content, use [Tabs](/docs/components/tabs)
