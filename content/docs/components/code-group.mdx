---
title: Code group
description: Tabbed code snippets for package managers, languages, and variants.
---

Use `CodeGroup` to show multiple related fenced blocks behind tabs.

## Basic usage

<CodeGroup>
  ```bash npm
  npm install
  ```

  ```bash pnpm
  pnpm install
  ```
</CodeGroup>

````tsx
<CodeGroup>
  ```bash npm
  npm install
  ```

  ```bash pnpm
  pnpm install
  ```
</CodeGroup>
````

Each child can set a label with a token after the language fence
(`` ```bash pnpm ``) or a `title` prop when the child is an element. If no label
is found, Shiso infers one from the language class and suffixes duplicates
(`bash`, `bash 2`, …).

A single child renders as plain content with no tab chrome. For non-code
alternate content, use [Tabs](/docs/components/tabs).
