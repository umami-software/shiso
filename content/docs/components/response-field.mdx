title: Response Field
description: Document object properties and schema fields.
---

Use `ResponseField` for response body fields, object properties, and similar
schema documentation.

## Props

- `name: string`
- `type?: string | number | boolean | null`
- `required?: boolean`
- `deprecated?: boolean`
- `children?: ReactNode`

## Basic usage

```tsx
<ResponseField name="id" type="string" required>
  Unique identifier for the resource.
</ResponseField>
```

<ResponseField name="id" type="string" required>
  Unique identifier for the resource.
</ResponseField>

## Optional and deprecated fields

```tsx
<ResponseField name="legacyField" type="number" deprecated>
  Removed in a future release.
</ResponseField>
```

<ResponseField name="legacyField" type="number" deprecated>
  Removed in a future release.
</ResponseField>

## Behavior notes

- HTML entities in string `type` values are decoded before rendering
- nest `ResponseField` under headings to document nested objects
