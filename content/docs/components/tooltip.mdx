---
title: Tooltip
description: Short hover and keyboard-focus hints.
---

Use `Tooltip` for brief definitions or clarifications without leaving the
sentence. The tip appears on hover and keyboard focus. Keep tips short — no
links or block content.

## Basic usage

The value of <Tooltip tip="Used to identify the current API key">API key</Tooltip> must be kept secret.

```tsx
<Tooltip tip="Used to identify the current API key">API key</Tooltip>
```

## Properties

<PropertiesTable>
<ResponseField name="tip" type="ReactNode">
  Hint text shown in the tooltip bubble.
</ResponseField>

<ResponseField name="children" type="ReactNode">
  Trigger content. The trigger is focusable and linked with `aria-describedby`.
</ResponseField>
</PropertiesTable>
