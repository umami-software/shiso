---
title: Tooltip
---

Use `Tooltip` to provide short inline hints.

## Supported props

- `tip?: ReactNode`
- `children?: ReactNode`

## Basic usage

```tsx
<Tooltip tip="Used to identify the current API key">API key</Tooltip>
```

The value of <Tooltip tip="Used to identify the current API key">API key</Tooltip> must be kept secret.

## Behavior notes

- the tip appears on hover and on keyboard focus
- the trigger is focusable and linked to the tip with `aria-describedby`
- keep tips short; they are not a place for links or block content
