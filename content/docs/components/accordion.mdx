---
title: Accordion
description: Expandable FAQ-style sections, alone or in a group.
---

Use `Accordion` for a single expandable block, or wrap several in
`AccordionGroup`.

## Single accordion

<Accordion title="Deploy" icon="rocket">
  Run `pnpm build` and publish `dist/client`.
</Accordion>

```tsx
<Accordion title="Deploy" icon="rocket">
  Run `pnpm build` and publish `dist/client`.
</Accordion>
```

## Accordion groups

Group related items with `AccordionGroup`. Set `defaultOpen` to expand the
first item (unless a child sets its own `defaultOpen`).

<AccordionGroup defaultOpen>
  <Accordion title="What is Shiso?">
    A docs site generator powered by Vite, React, and MDX.
  </Accordion>
  <Accordion title="What does it support?">
    Navigation, branding, SEO, and built-in MDX components.
  </Accordion>
</AccordionGroup>

```tsx
<AccordionGroup defaultOpen>
  <Accordion title="What is Shiso?">
    A docs site generator powered by Vite, React, and MDX.
  </Accordion>
  <Accordion title="What does it support?">
    Navigation, branding, SEO, and built-in MDX components.
  </Accordion>
</AccordionGroup>
```

For a single collapsible without group styling, use
[Expandable](/docs/components/expandable).

## Properties

### Accordion

<ResponseField name="title" type="ReactNode">
  Summary label shown in the header.
</ResponseField>

<ResponseField name="icon" type="ReactNode | string">
  Lucide icon name or element shown before the title.
</ResponseField>

<ResponseField name="defaultOpen" type="boolean" default="false">
  Whether the accordion starts expanded.
</ResponseField>

<ResponseField name="children" type="ReactNode">
  Content revealed when open.
</ResponseField>

### AccordionGroup

<ResponseField name="defaultOpen" type="boolean" default="false">
  When `true`, opens the first child that does not set its own `defaultOpen`.
</ResponseField>

<ResponseField name="children" type="ReactNode">
  One or more `Accordion` items. Empty groups render nothing.
</ResponseField>
