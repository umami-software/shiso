---
title: Columns
description: Place any content side by side in a responsive grid.
---

Use `Columns` and `Column` for multi-column layouts that are not pure card
grids. Columns collapse to a single column below 768px. Prefer
[CardGroup](/docs/components/card) when every child is a `Card`.

## Basic usage

<Columns cols={2}>
  <Column>
    **Install**

    ```bash
    pnpm install
    ```
  </Column>
  <Column>
    **Run**

    ```bash
    pnpm dev
    ```
  </Column>
</Columns>

````tsx
<Columns cols={2}>
  <Column>
    **Install**

    ```bash
    pnpm install
    ```
  </Column>
  <Column>
    **Run**

    ```bash
    pnpm dev
    ```
  </Column>
</Columns>
````

## Properties

### Columns

<PropertiesTable>
<ResponseField name="cols" type="1 | 2 | 3 | 4" default="2">
  Number of columns. Clamped to the range 1–4.
</ResponseField>

<ResponseField name="children" type="ReactNode">
  Column content. Prefer wrapping each cell in `Column`.
</ResponseField>
</PropertiesTable>

### Column

<PropertiesTable>
<ResponseField name="children" type="ReactNode">
  Content for one column.
</ResponseField>
</PropertiesTable>
