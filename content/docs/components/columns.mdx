---
title: Columns
description: Place any content side by side in a responsive grid.
---

Use `Columns` and `Column` for multi-column layouts that are not pure card
grids.

## Props

### `Columns`

- `cols?: 1 | 2 | 3 | 4` (defaults to `2`)
- `children?: ReactNode`

### `Column`

- `children?: ReactNode`

## Basic usage

````mdx
<Columns cols={2}>
  <Column>
    **Install**

    ```bash
    pnpm install
    ```
  </Column>
  <Column>
    **Run**

    ```bash
    pnpm dev
    ```
  </Column>
</Columns>
````

<Columns cols={2}>
  <Column>
    **Install**

    ```bash
    pnpm install
    ```
  </Column>
  <Column>
    **Run**

    ```bash
    pnpm dev
    ```
  </Column>
</Columns>

## With cards

```tsx
<Columns cols={3}>
  <Card title="Quickstart" icon="rocket" href="/docs/quickstart" />
  <Card title="Configure" icon="settings" href="/docs/configuration" />
  <Card title="Write" icon="book-open" href="/docs/writing-content" />
</Columns>
```

## Behavior notes

- columns collapse to a single column below 768px
- `cols` is clamped to the range 1–4
- prefer [CardGroup](/docs/components/card) when every child is a `Card`
