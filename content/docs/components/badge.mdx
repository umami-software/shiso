Use `Badge` inside text or as a standalone status label.

## Basic usage

<Badge>Badge</Badge>

```tsx
<Badge>Badge</Badge>
```

## Icons

Named icons use the Lucide icon registry. You can also pass an image URL, a local image path, or a rendered React node.

<Badge icon="circle-check" color="green">Verified</Badge>{' '}
<Badge icon="clock" color="orange">Pending</Badge>{' '}
<Badge icon="ban" color="red">Blocked</Badge>

```tsx
<Badge icon="circle-check" color="green">Verified</Badge>
<Badge icon="clock" color="orange">Pending</Badge>
<Badge icon="ban" color="red">Blocked</Badge>
```
