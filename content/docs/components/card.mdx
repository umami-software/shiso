## Typed cards

Typed cards use the matching callout theme and default icon. Set `icon` to
override the default.

<CardGroup cols={2}>
  <Card title="Note card" type="note">Supporting information.</Card>
  <Card title="Info card" type="info">Additional context.</Card>
  <Card title="Warning card" type="warning">Something needs attention.</Card>
  <Card title="Tip card" type="tip">A helpful suggestion.</Card>
  <Card title="Check card" type="check">A successful result.</Card>
  <Card title="Danger card" type="danger">A risky or destructive action.</Card>
</CardGroup>

```tsx
<Card title="Note card" type="note">Supporting information.</Card>
<Card title="Info card" type="info">Additional context.</Card>
<Card title="Warning card" type="warning">Something needs attention.</Card>
<Card title="Tip card" type="tip">A helpful suggestion.</Card>
<Card title="Check card" type="check">A successful result.</Card>
<Card title="Danger card" type="danger">A risky or destructive action.</Card>
```

Cards with `href` render as links; without it they are static containers.
External `href` values open in a new tab. For mixed content side by side, use
[Columns](/docs/components/columns).

## Properties

### Card

<PropertiesTable>
<ResponseField name="title" type="ReactNode">
  Card heading.
</ResponseField>

<ResponseField name="href" type="string">
  Optional link destination. When set, the card is interactive.
</ResponseField>

<ResponseField name="icon" type="ReactNode | string">
  Lucide icon name, image URL or path, or rendered element.
</ResponseField>

<ResponseField name="color" type="string">
  CSS color applied to the icon.
</ResponseField>

<ResponseField name="img" type="string">
  Image shown above the body.
</ResponseField>

<ResponseField name="cta" type="string">
  Trailing action label.
</ResponseField>

<ResponseField name="horizontal" type="boolean" default="false">
  Lay out icon, title, and body in a row.
</ResponseField>

<ResponseField name="arrow" type="boolean">
  Show or hide the trailing arrow. External links show it by default.
</ResponseField>

<ResponseField name="type" type="'note' | 'info' | 'warning' | 'tip' | 'check' | 'danger'">
  Apply the matching callout background, border, text color, and default icon.
</ResponseField>

<ResponseField name="children" type="ReactNode">
  Body content.
</ResponseField>
</PropertiesTable>

### CardGroup

<PropertiesTable>
<ResponseField name="cols" type="1 | 2 | 3 | 4" default="2">
  Number of columns in the grid.
</ResponseField>

<ResponseField name="children" type="ReactNode">
  One or more `Card` children.
</ResponseField>
</PropertiesTable>
