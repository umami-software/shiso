## Horizontal card

<Card title="Changelog" icon="history" href="/docs" horizontal cta="Read more" />

```tsx
<Card title="Changelog" icon="history" href="/docs" horizontal cta="Read more" />
```

Cards with `href` render as links; without it they are static containers.
External `href` values open in a new tab. For mixed content side by side, use
[Columns](/docs/components/columns).

## Properties

### Card

<ResponseField name="title" type="ReactNode">
  Card heading.
</ResponseField>

<ResponseField name="href" type="string">
  Optional link destination. When set, the card is interactive.
</ResponseField>

<ResponseField name="icon" type="ReactNode | string">
  Lucide icon name or element.
</ResponseField>

<ResponseField name="img" type="string">
  Image shown above the body.
</ResponseField>

<ResponseField name="cta" type="string">
  Label shown next to the arrow.
</ResponseField>

<ResponseField name="horizontal" type="boolean" default="false">
  Lay out icon, title, and body in a row.
</ResponseField>

<ResponseField name="arrow" type="boolean">
  Show a trailing arrow. Defaults to `true` when `href` is set.
</ResponseField>

<ResponseField name="children" type="ReactNode">
  Body content.
</ResponseField>

### CardGroup

<ResponseField name="cols" type="1 | 2 | 3 | 4" default="2">
  Number of columns in the grid.
</ResponseField>

<ResponseField name="children" type="ReactNode">
  One or more `Card` children.
</ResponseField>
