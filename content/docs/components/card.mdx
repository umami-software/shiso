---
title: Card
description: Linked or static summary cards, alone or in a grid.
---

Use `Card` and `CardGroup` for scannable links or feature summaries.

## Props

### `Card`

- `title?: ReactNode`
- `href?: string`
- `icon?: ReactNode | string` — lucide name or element
- `img?: string` — image shown above the body
- `cta?: string` — label shown next to the arrow
- `horizontal?: boolean` — icon, title, and body in a row
- `arrow?: boolean` — defaults to `true` when `href` is set
- `children?: ReactNode`

### `CardGroup`

- `cols?: 1 | 2 | 3 | 4` (defaults to `2`)
- `children?: ReactNode`

## Basic usage

```tsx
<Card title="API Reference" icon="code" href="/docs/components/response-field">
  Learn how to model response schemas.
</Card>
```

<Card title="API Reference" icon="code" href="/docs/components/response-field">
  Learn how to model response schemas.
</Card>

## Card group

```tsx
<CardGroup cols={2}>
  <Card title="Quickstart" icon="rocket" href="/docs/quickstart">
    Run Shiso and make your first change.
  </Card>
  <Card title="Components" icon="book-open" href="/docs/components">
    Browse all docs components.
  </Card>
</CardGroup>
```

## Behavior notes

- cards with `href` render as links; without it they are static containers
- external `href` values open in a new tab
- for mixed content side by side, use [Columns](/docs/components/columns)
