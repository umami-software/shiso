title: Examples
description: Request and response payload blocks for API reference pages.
---

Use `RequestExample` and `ResponseExample` to wrap sample payloads under an
endpoint heading. Pair them under the same heading to document a request and
its response. Nest [Code Group](/docs/components/code-group) inside either
component to show multiple languages.

## Request example

<RequestExample title="Create user request">
  ```json
  {
    "email": "user@example.com",
    "name": "Ada Lovelace"
  }
  ```
</RequestExample>

````mdx

````

## Properties

Both components accept the same props:

<ResponseField name="title" type="ReactNode">
  Header label. Defaults to `"Request example"` or `"Response example"`.
</ResponseField>

<ResponseField name="children" type="ReactNode">
  Payload content, usually a fenced code block.
</ResponseField>
