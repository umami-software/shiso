---
title: Examples
description: Request and response payload blocks for API reference pages.
---

Use `RequestExample` and `ResponseExample` to wrap sample payloads under an
endpoint heading.

## Props

Both components accept:

- `title?: ReactNode` — defaults to `"Request example"` /
  `"Response example"`
- `children?: ReactNode`

## Request example

````mdx
<RequestExample title="Create user request">
  ```json
  {
    "email": "user@example.com",
    "name": "Ada Lovelace"
  }
  ```
</RequestExample>
````

<RequestExample title="Create user request">
  ```json
  {
    "email": "user@example.com",
    "name": "Ada Lovelace"
  }
  ```
</RequestExample>

## Response example

````mdx
<ResponseExample>
  ```json
  {
    "id": "usr_1",
    "email": "user@example.com"
  }
  ```
</ResponseExample>
````

<ResponseExample>
  ```json
  {
    "id": "usr_1",
    "email": "user@example.com"
  }
  ```
</ResponseExample>

## Behavior notes

- pair them under the same heading to document a request and its response
- nest [Code Group](/docs/components/code-group) inside either component to
  show multiple languages
