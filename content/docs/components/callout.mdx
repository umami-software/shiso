---
title: Callout
---

Use callouts to highlight important content blocks.

## Supported components

- `Callout`
- `Note`
- `Tip`
- `Warning`
- `Info`
- `Check`
- `Danger`

## `Callout` props

- `variant?: 'note' | 'tip' | 'warning' | 'info' | 'check' | 'danger'`
- `title?: ReactNode`
- `icon?: ReactNode | string` (an icon name such as `"flame"`)
- `children?: ReactNode`

## Generic callout

```tsx
<Callout variant="note" title="Heads up">
  This is a custom callout body.
</Callout>
```

<Callout variant="note" title="Heads up">
  This is a custom callout body.
</Callout>

## Variants

### Note

<Note>Use this for neutral supplemental information.</Note>

### Tip

<Tip>Use this for best practices and helpful shortcuts.</Tip>

### Warning

<Warning>Use this for risky operations or destructive behavior.</Warning>

### Info

<Info>Use this for contextual details users should know.</Info>

### Check

<Check>Use this for success or completion states.</Check>

### Danger

<Danger>Use this for irreversible actions and data loss.</Danger>

## Custom icon

```tsx
<Callout variant="tip" icon="flame" title="Hot path">
  This request is on the critical path.
</Callout>
```

<Callout variant="tip" icon="flame" title="Hot path">
  This request is on the critical path.
</Callout>

## Behavior notes

- `Note`, `Tip`, `Warning`, `Info`, `Check`, and `Danger` are wrappers around `Callout`
- if no `title` is provided, only the body content is rendered
- `icon` accepts an icon name or a rendered element, and overrides the variant default
