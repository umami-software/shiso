title: Callout

---

Use callouts to pull important information out of the main flow.

## Components

- `Callout` — generic, with a `variant` prop
- `Note`, `Tip`, `Warning`, `Info`, `Check`, `Danger` — fixed-variant wrappers

## `Callout` props

- `variant?: 'note' | 'tip' | 'warning' | 'info' | 'check' | 'danger'`
- `title?: ReactNode`
- `icon?: ReactNode | string` — lucide name or element; overrides the variant default
- `children?: ReactNode`

## Generic callout

```tsx
<Callout variant="note" title="Heads up">
  This is a custom callout body.
</Callout>
```

<Callout variant="note" title="Heads up">
  This is a custom callout body.
</Callout>

## Variants

### Note

<Note>Neutral supplemental information.</Note>

### Tip

<Tip>Best practices and helpful shortcuts.</Tip>

### Warning

<Warning>Risky operations or destructive behavior.</Warning>

### Info

<Info>Contextual details readers should know.</Info>

### Check

<Check>Success or completion states.</Check>

### Danger

<Danger>Irreversible actions and data loss.</Danger>

## Custom icon

```tsx
<Callout variant="tip" icon="flame" title="Hot path">
  This request is on the critical path.
</Callout>
```

<Callout variant="tip" icon="flame" title="Hot path">
  This request is on the critical path.
</Callout>

## Behavior notes

- shortcut components are thin wrappers around `Callout`
- without a `title`, only the body is shown
- `icon` accepts a lucide name string or a rendered element
