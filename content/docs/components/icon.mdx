---
title: Icon
description: Render lucide icons by name, or pass names to other components.
---

Use `Icon` for inline icons, or pass the same names to any component that
accepts an `icon` prop (`Card`, `Callout`, `Accordion`, and more).

Names are case-insensitive and accept `circle-check`, `circle_check`, or
`CircleCheck`. They are collected from content and `docs.json` at build time
into `src/lib/icon-registry.generated.ts`. An unrecognized name renders
nothing and logs a warning in development.

## Basic usage

Deploy your site <Icon icon="rocket" /> in one command.

```tsx
Deploy your site <Icon icon="rocket" /> in one command.
```

## Sizing and color

<Icon icon="circle-check" size={24} color="#16a34a" />

```tsx
<Icon icon="circle-check" size={24} color="#16a34a" />
```

## Properties

<PropertiesTable>
<ResponseField name="icon" type="string">
  A [lucide](https://lucide.dev/icons) icon name.
</ResponseField>

<ResponseField name="src" type="string">
  Image path or URL. Used instead of `icon` when set.
</ResponseField>

<ResponseField name="color" type="string">
  CSS color for the icon stroke/fill.
</ResponseField>

<ResponseField name="size" type="number" default="16">
  Icon size in pixels.
</ResponseField>

<ResponseField name="className" type="string">
  Extra class names on the rendered element.
</ResponseField>
</PropertiesTable>
