## Ordered lists

```markdown
1. First item
2. Second item
3. Third item
```

1. First item
2. Second item
3. Third item

## Unordered lists

Use `-`, `*`, or `+` markers:

```markdown
- First item
- Second item
- Third item
```

- First item
- Second item
- Third item

## Nested lists

Indent nested items with two or more spaces:

```markdown
1. Parent
   - Child A
   - Child B
2. Next parent
```

1. Parent
   - Child A
   - Child B
2. Next parent

## Task lists

GitHub-flavored Markdown task lists are supported:

```markdown
- [x] Build docs route
- [x] Add navigation to `docs.json`
- [ ] Write more examples
```

- [x] Build docs route
- [x] Add navigation to `docs.json`
- [ ] Write more examples

For multi-step procedures with numbered circles and titles, prefer the
[Steps](/docs/components/steps) component.
