## Standalone pages

The top-level `pages` key declares routes that live outside the docs
navigation — a landing page, an about page, anything that should not appear in
the sidebar. Each entry maps a route path to a TSX, MDX, or Markdown file under
`content/pages/`:

```json
{
  "pages": [
    { "path": "/", "page": "home" },
    { "path": "/about", "page": "about", "title": "About us" }
  ]
}
```

- `path`: the route, starting with `/`. An entry for `/` becomes the site
  home page, replacing the default redirect to the first docs page — the
  header brand link then points at `/` too.
- `page`: the file slug under `content/pages`, so `"home"` renders
  `content/pages/home.tsx`, `.mdx`, or `.md`. TSX takes precedence when more
  than one matching file exists.
- `title`: optional document title for the browser tab and social previews.
  Frontmatter `title` wins when both are set.

## Layout

Standalone pages render with the site chrome — banner, header, and footer —
but no sidebar, table of contents, or previous/next links. The content spans
the full container width. Markdown and MDX pages receive the same typography
styles and [components](/docs/components) as documentation pages:

```mdx
# Build docs people actually read

<Columns cols={2}>
  <Card title="Get started" icon="rocket" href="/docs/installation">
    Install Shiso and ship your first page in minutes.
  </Card>
  <Card title="Components" icon="layout-grid" href="/docs/components">
    Cards, tabs, callouts, and more — ready to compose.
  </Card>
</Columns>
```

TSX pages render as regular React components without the `docs-markdown`
wrapper, so they own their spacing, typography, and layout. Export a
`frontmatter` object for page metadata and per-page options:

```tsx
import { Button } from '@umami/shiso/components';

export const frontmatter = {
  title: 'Welcome',
  description: 'Product documentation for Acme.',
  search: false,
};

export default function Home() {
  return (
    <div className="py-16 text-center">
      <h1 className="text-6xl font-bold">Build docs people actually read</h1>
      <Button href="/docs" icon="rocket">Get started</Button>
    </div>
  );
}
```

All [built-in components](/docs/components) are available from
`@umami/shiso/components` in TSX pages. In MDX they remain available without
imports.

## Behavior notes

- Paths must not collide with docs URLs, sit inside the docs prefix, or use
  `/404` (reserved for the error page).
- Standalone pages are prerendered like docs pages, included in
  `sitemap.xml`, and support last-modified timestamps. Markdown and MDX pages
  are also published with a raw Markdown copy (`/about.md`); TSX pages are not.
  Set `noindex: true` in frontmatter to keep one out of the sitemap and search
  engines.
- They are not included in site search.
