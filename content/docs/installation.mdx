title: Installation
description: Run Shiso locally and build the static site.
---

This guide sets up Shiso from a fresh checkout.

## Prerequisites

- Node.js 20+
- pnpm (or npm/yarn)

## 1. Install dependencies

```bash
pnpm install
```

## 2. Confirm key files

```text
.
├── content
│   └── docs
│       └── index.mdx
├── docs.json
├── docs.schema.json
└── src
```

- `content/docs` holds your pages
- `docs.json` configures the whole site
- `docs.schema.json` powers editor autocomplete and build validation

## 3. Configure navigation

Edit `docs.json`:

```json
{
  "$schema": "./docs.schema.json",
  "theme": "mint",
  "name": "My Docs",
  "navigation": {
    "tabs": [
      {
        "tab": "Documentation",
        "groups": [
          {
            "group": "Getting started",
            "pages": ["index", "installation"]
          }
        ]
      }
    ]
  }
}
```

## 4. Create matching content files

Each page slug in `navigation` must map to a file in `content/docs`:

```text
content/docs/index.mdx
content/docs/installation.mdx
```

## 5. Run locally

```bash
pnpm dev
```

Open `/docs` and confirm:

1. content renders
2. side navigation matches `docs.json`
3. prev/next links follow navigation order
4. heading anchors appear in "On this page"

## 6. Build for production

```bash
pnpm build
```

The build validates `docs.json`, prerenders every page to static HTML in
`dist/client`, and writes `sitemap.xml`, redirect pages, and a `404.html`
fallback. The output deploys to any static host — no server required.

Preview the production build locally:

```bash
pnpm preview
```
