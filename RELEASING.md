# Releasing Shiso

This repository publishes two independent npm packages:

- `shiso`: the upgradeable framework, using `shiso-vX.Y.Z` tags.
- `create-shiso-app`: the one-time project generator, using
  `create-shiso-app-vX.Y.Z` tags.

Release `shiso` before a generator version that depends on it.

## Prepare a framework release

1. Update `packages/shiso/package.json` without creating a tag:

   ```bash
   pnpm --dir packages/shiso version patch --no-git-tag-version
   ```

2. Add the matching dated section to `packages/shiso/CHANGELOG.md`.
3. Update the `shiso` range generated by `create-shiso-app` when appropriate.
4. Run:

   ```bash
   pnpm release:check:shiso
   pnpm test:create-app
   ```

5. Merge the changes, then create the matching tag from that commit:

   ```bash
   git tag -a shiso-v0.62.0 -m "shiso 0.62.0"
   git push origin shiso-v0.62.0
   ```

The tag starts `.github/workflows/release-shiso.yml`, which validates, packs,
publishes with provenance, and creates the GitHub release.

## Prepare a generator release

1. Update `packages/create-shiso-app/package.json`:

   ```bash
   pnpm --dir packages/create-shiso-app version patch --no-git-tag-version
   ```

2. Add the matching dated section to `packages/create-shiso-app/CHANGELOG.md`.
3. Confirm its generated `shiso` dependency refers to an already-published
   framework version.
4. Run:

   ```bash
   pnpm release:check
   pnpm test:create-app
   ```

5. Merge and tag the reviewed commit:

   ```bash
   git tag -a create-shiso-app-v0.2.0 -m "create-shiso-app 0.2.0"
   git push origin create-shiso-app-v0.2.0
   ```

The existing `.github/workflows/release.yml` publishes the generator.

Prerelease versions such as `1.0.0-rc.1` publish under npm's `next` tag;
stable versions publish under `latest`. Published versions and their Git tags
are immutable—fix a bad release with a new patch version.

## One-time npm bootstrap

Each package must exist before npm allows its trusted publisher to be
configured. Bootstrap `shiso` first, then `create-shiso-app` if needed:

1. Authenticate locally with the npm owner account protected by two-factor
   authentication.
2. Publish the reviewed package once:

   ```bash
   pnpm --dir packages/shiso publish --access public
   ```

3. In that npm package's settings, configure a GitHub Actions trusted
   publisher:

   - Organization: `umami-software`
   - Repository: `shiso`
   - Workflow: `release-shiso.yml` for `shiso`, or `release.yml` for
     `create-shiso-app`
   - Environment: `npm`

4. Push the matching release tag. The workflow detects the existing npm
   version, skips republishing, and creates the GitHub release.

After verifying trusted publishing, require two-factor authentication and
disable token-based publication. The workflows do not need an npm token.
